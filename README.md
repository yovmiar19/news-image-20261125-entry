## Entry

`main.ts` (Node 22, standard library only) copies `entry.png` — the 1024×1024 image,
174,625 bytes — to `/output/entry.png`. Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The two grader runs write byte-identical files (the program only copies the image).
